PEGBLOOM — a pachinko garden defense. Drop the dawn through the great pegboard: aim each dewdrop, ride the cascade multiplier, and land in the bloom cups while four garden pests and the Duskfather boss work the board against you. Between the nine showers, draft charms and place five contraptions to bend every drop your way. Deterministic: seeded physics and visuals only, the same seed replays the same run.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
